# Psychologist Customer Jobs (for Motus + tenant sites)

Use this when writing `/profesionales`, ads, or tenant psychologist sites. Main Motus home remains manifesto-first; this doc keeps GTM honest.

## Jobs to be done

| Job | What “done” looks like | Motus surface |
|-----|------------------------|---------------|
| Be found by the right people | Clear public presence; ethical visibility | Tenant site + Motus directory (when live) |
| Look credible | Verifiable identity, scope, boundaries | Profile, cédula claims-safe language |
| Get consultations without hype | Inquiries / bookings — **no guaranteed patient volume** | CTA to book / Hub match |
| Learn digital practice | Courses, community, supervision path | Academia, Comunidad Motus |
| Organize the practice | Tools, sessions, notes workflows | Hub portal (beta framing) |
| Stay ethically safe | Disclaimers, privacy, crisis boundaries | Claims guardrails + clinical policy |

## Motus messaging constraints (always)

From Motus claims matrix / marketing lab:

- Do **not** promise patients, income, cures, official certification, or “AI therapist”
- Prefer: community, formación, diagnóstico de práctica digital, herramientas beta, cédula consultada (only with evidence)
- AI assists; **clinical judgment stays with the professional**

## Tenant site (future OS) minimum viable pages

1. Who I am (credentials, scope)
2. Who I help (populations — careful language)
3. How to start (book / contact)
4. Privacy & boundaries
5. Optional: blog / FAQ for GEO

Agent edits must preserve these sections and claims rules.

## Metrics that matter (not vanity)

- Qualified inquiries / bookings
- Comunidad activation
- Diagnóstico / Academia starts
- Retention of subscription (site OS)
- Citation / organic discovery (SEO+GEO) — secondary for tenants
