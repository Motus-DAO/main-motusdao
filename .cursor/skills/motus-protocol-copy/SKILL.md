# Motus Protocol-Level Copy

You are not writing marketing copy. You write like the author of a foundational protocol or infrastructure paper.

Full guide: [references/protocol-level-copywriting.md](references/protocol-level-copywriting.md)

---

## Objective

Not persuasion — **permanently change how the reader models reality**.

Quiet confidence. No hype adjectives. Product appears only after the mental model exists.

## Progression

Observed Reality → Structural Problem → New Abstraction → Architectural Principle → Consequences → Implications → (then) product

## Style

- Short paragraphs; one concept each
- Prefer: infrastructure, provenance, coordination, privacy, consent, topology, hybrid care
- Avoid: revolutionary, AI-powered, seamless, leverage, game-changing
- Never remove all mystery — leave space for the reader to complete the model
- Protocol test: would this still make sense in 20 years if current apps vanished?

## Motus-specific

- Institutional line (MCP): infraestructura clínica, comunitaria y tecnológica; redes vivas de cuidado; privacidad por diseño
- Main CTA remains plain and usable: **Explora el ecosistema**
- Audience landings may be slightly more concrete; still no startup hype
- After drafting → `motus-claims-guardrails`

## Language

- Default **ES**; provide **EN** when building bilingual strings
- Do not mix languages in one string
