# Motus Claims Guardrails

Run before shipping any public copy (Motus home, audience landings, tenant sites).

Source patterns: Motus marketing-lab clinical claims + MCP `claims_guardrails`.

---

## High-risk — flag / rewrite

| Claim type | Unsafe | Safer framing |
|------------|--------|----------------|
| Patients | Guaranteed patients / agenda llena | Posible visibilidad; sin garantía |
| Income | Guaranteed income | No income promises |
| Outcomes | Cures, guaranteed clinical results | No outcome guarantees |
| Certification | Official specialty / license from Motus | Formación; Pase Motus ≠ cédula |
| AI | AI replaces therapist / diagnoses | AI-human hybrid; judgment stays with professional |
| Clinic | “Clínica autorizada” without structure | Portal / herramientas beta + disclaimers |
| Verification | “Calidad clínica verificada” from ID only | Cédula consultada en RN + date + scope |

---

## Checklist

- [ ] No guaranteed patients, income, or cures
- [ ] No fake certification / regulatory approval
- [ ] AI does not replace clinical judgment
- [ ] Privacy / crisis boundaries acknowledged where relevant
- [ ] Beta / in-development framed honestly where true
- [ ] Tenant sites: credentials only with evidence

## Output format

When reviewing, return:

1. **Blockers** (must fix)
2. **Soften** (rewrite suggestions)
3. **OK** (safe as written)

If blockers exist, do not treat the copy as publish-ready.
